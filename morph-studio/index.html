Orientation

Generate sends the front photo to the AI 3D service and returns a realistic head of the patient in about one to three minutes; then confirm the landmarks and calibrate the scale. You can also load a .glb from a scanning app. Without a model, the photos are projected onto a generic head.

Scale & measurements

Use the Measure tool: click two points whose real distance you know (pupil to pupil is usually 60–65 mm), then Set as… on that measurement to calibrate. Measurements update live while you sculpt and show the change.

Avatar photos

The photos are projected onto a generic head. Use Align so the eyes and chin match. Areas without a photo are shown in a neutral skin tone.

AI settings

Claude reads the notes, the photos and the feedback and plans the simulation; OpenAI's image model paints the photorealistic result. Paste the keys once; they are kept in this browser only and sent to this app's own server functions with each AI request. Claude key: console.anthropic.com → API keys. OpenAI key: platform.openai.com → API keys.

For a clinic-wide setup an administrator can instead set ANTHROPIC_API_KEY, OPENAI_API_KEY and MESHY_API_KEY in the Vercel project's environment variables; keys set there take priority and nothing needs to be entered here.
